# PyBirds

一个使用 `pygame` 和 `pymunk` 构建的愤怒的小鸟风格游戏示例。游戏提供精致的卡通画面、可交互的弹弓操作，以及基于真实物理的猪和木块/钢块结构。

## 功能亮点
- **物理引擎支持**：借助 `pymunk` 实现真实的碰撞、弹跳和破坏效果。
- **精致画面**：渐变天空、动态云彩、柔和阴影与抛物线瞄准线带来更完整的视觉体验。
- **完整操作体验**：按住鼠标拖拽弹弓即可蓄力发射，按 `R` 重置关卡，按 `Space` 可追加新的小鸟。
- **自适应镜头**：镜头会自动跟随正在飞行的小鸟，并带有轻微的视差背景效果。

## 运行环境
- Python 3.9+
- pygame
- pymunk

建议使用虚拟环境安装依赖：

```bash
python -m venv .venv
source .venv/bin/activate  # Windows 用户使用 .venv\Scripts\activate
pip install -r requirements.txt
```

## 启动游戏

```bash
python -m angry_birds.game
```

首次运行会尝试初始化音频设备。如果当前环境没有音频输出设备，游戏仍然可以正常运行，只是不会播放发射音效。

## 操作说明
- **按住鼠标左键拖拽**：拉动弹弓蓄力。
- **松开鼠标左键**：发射当前小鸟。
- **R**：重置当前关卡。
- **Space**：在弹弓旁补充一只新的小鸟（最多 4 只）。
- **Esc 或关闭窗口**：退出游戏。
